## YanBi 言笔 — Voice typing for Windows · Windows 语音输入

Press a hotkey, speak, and the transcript is pasted into whatever you're typing. Cloud streaming ASR with optional DeepSeek polishing and a hotword correction loop.
按热键说话，转写结果自动上屏到当前输入框。云端流式语音识别 + 可选 DeepSeek 书面语整理 + 热词纠错闭环。
